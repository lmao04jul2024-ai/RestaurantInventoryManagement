# Deck: Server (Session 2, 45 min)

> Narration script — one line per slide. Exercise at the end is mandatory.

## Slide 1 — Your tool
- You live in the staff **dashboard** → **Orders** (the order board).

## Slide 2 — Taking an order
- **Orders → New order**: pick a table (or takeaway), add menu items.
- Items show the **current effective price** — happy-hour/time-window rules apply automatically.

## Slide 3 — Availability is enforced
- 86'd items are blocked at order time, with the item name — pick an alternative; there is no override.

## Slide 4 — The ticket goes live
- Submit → the ticket appears on the **Kitchen Display** instantly, no refresh.
- Status flows PENDING → CONFIRMED → PREPARING → READY; you serve at READY.

## Slide 5 — Group orders
- Start one from an order, share the 6-character code; guests add their own items.
- As host you **Convert** it to one real ticket when the party is done — or **Cancel** it.

## Slide 6 — Payment & close-out
- Open the order → **Pay** → method (card/cash/…). Status flips to PAID, ticket finalizes.
- Loyalty points accrue automatically at payment — never "add points" by hand (there is no such button).

## Slide 7 — What you can't do (by design)
- Edit prices/availability (Manager), see other tenants' data (impossible), edit items on a placed ticket (cancel & re-order or ask a Manager).

## Slide 8 — When things stall
- Live connections pause when the internet drops; reload to reconnect.
- No offline queue — check **Orders** before repeating any action.

## Exercise (do it now)
Run a 2-person group order end-to-end on staging: create it, join from a second
browser, convert, pay. Show the trainer the PAID ticket.
