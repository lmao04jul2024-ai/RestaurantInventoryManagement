# User Manuals by Role (Week 23.2)

One guide per role, written for non-technical staff:

| Role | Guide | What they do |
|---|---|---|
| **Customer** | [customer.md](./customer.md) | Browse menu, order, pay, review, loyalty points |
| **Server** | [server.md](./server.md) | Take orders, manage tables, close out |
| **Kitchen** | [kitchen.md](./kitchen.md) | Kitchen display, ticket lifecycle, availability |
| **Manager** | [manager.md](./manager.md) | Menu, inventory, staff, analytics, promos, loyalty |
| **Admin** | [admin.md](./admin.md) | Everything + tenants, branding, flags, audit, security |

The full feature walkthrough (screens, fields, edge cases) lives in
[`docs/admin/README.md`](../admin/README.md); these manuals are the "day one"
version per person. Deployment/ops staff should read
[`docs/deployment/README.md`](../deployment/README.md) instead.
