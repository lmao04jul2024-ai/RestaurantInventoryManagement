# Kitchen Guide

You live on the **Kitchen Display** (`Dashboard → Kitchen Display`).

## 1. Reading the board
Tickets arrive in real time, grouped by state:

`QUEUED → PREPARING → READY` → picked up / served.

Each ticket shows the order number, items with quantities, any special
instructions, and an elapsed timer. Priority = oldest first; overdue tickets
highlight.

## 2. Working a ticket
- Tap **Start** when cooking begins.
- Tap **Ready** when plated. The front of house sees READY immediately.
- State changes are one-way along the pipeline — you can't accidentally send a
  finished ticket back to QUEUED.

## 3. Item availability (86'ing)
If you run out of something: **Menu → item → toggle Available off**. It
instantly disappears from the customer site and is rejected at order time with
the item name. Turn it back on when restocked. Items with **availability
windows** (e.g. brunch items 9:00–11:30) flip automatically — you only manage
the emergency 86 switch.

## 4. Capacity indicator
The header shows current load (open tickets). When the kitchen is slammed, tell
a Manager — they can extend prep estimates or pause scheduling from the
analytics view.

## 5. Roles
Kitchen accounts can see the board and toggle availability. They **cannot**
edit prices, see analytics, or manage staff — that's Manager/Admin territory.
