# Glossary - Terminology & Definitions 📖

## 📋 Overview
Common terminology used throughout the cross-platform restaurant management system.

## 🏗️ Architecture Terms

| Term | Definition |
|------|------------|
| **Cross-Platform** | Single codebase that runs on multiple platforms (mobile, web) |
| **PWA** | Progressive Web App - web app with native-like capabilities |
| **React Native** | Framework for building native mobile apps using React |
| **Next.js** | React framework for server-side rendering and static generation |
| **Capacitor** | Framework for wrapping web apps as native mobile apps |
| **Feature-Sliced Architecture** | Organizing code by features rather than technical layers |
| **Design Tokens** | Reusable design variables (colors, spacing, typography) |
| **State Management** | System for managing application data across components |
| **API-First** | Design approach where API is designed before implementation |

## 👥 User Roles

| Term | Definition |
|------|------------|
| **Customer** | End-user who browses menu and places orders |
| **Server/Waiter** | Front-of-house staff who take orders and manage tables |
| **Kitchen Staff** | Back-of-house team who prepare food and update order status |
| **Manager** | Oversight role for inventory, staff, and performance |
| **Admin** | Super-user who configures system for multiple restaurants |
| **Guest** | Customer who hasn't logged in or created account |

## 🍽️ Restaurant Operations

| Term | Definition |
|------|------------|
| **BOM** | Bill of Materials - ingredients needed per menu item |
| **Stock Level** | Current snapshot of available inventory |
| **Modifier** | Customization option (e.g., extra cheese, no onions) |
| **Prep Time** | Average minutes from order to ready |
| **Table Turn** | Number of times a table is served per day |
| **Turnover** | Time a table spends occupied |
| **Cover Charge** | Per-person fixed fee |
| **Complimentary** | Free item offered to guests |
| **KDS** | Kitchen Display System - digital order board for kitchen |

## 📱 Order Types

| Term | Definition |
|------|------------|
| **Dine-In** | Customer seated at a table, ordering through app |
| **Takeout** | Order ready for pickup, not consumed on premises |
| **Delivery** | Order sent to customer's location |
| **Order Status** | Current state of order (pending, confirmed, preparing, ready, served) |
| **Order Number** | Unique identifier for tracking orders |
| **Split Bill** | Dividing payment among multiple customers |

## 🎨 Customization & Branding

| Term | Definition |
|------|------------|
| **Theme** | Visual styling (colors, fonts, spacing) for a client |
| **White-Label** | Product rebranded for another company |
| **Multi-Tenancy** | Single system serving multiple clients with data isolation |
| **Feature Flag** | Toggle to enable/disable features without code changes |
| **Configuration** | Settings that control system behavior per client |
| **Tenant** | Individual client/restaurant using the system |

## 🔗 Integration Terms

| Term | Definition |
|------|------------|
| **QappR** | Third-party system for extended functionality |
| **API** | Application Programming Interface - system communication |
| **Webhook** | HTTP callback for real-time event notifications |
| **Sync** | Data synchronization between systems |
| **Deep Link** | URL that opens specific content in mobile app |
| **QR Code** | Machine-readable code for quick mobile access |

## 📊 Performance Metrics

| Term | Definition |
|------|------------|
| **First Paint** | Time until first content appears on screen |
| **Latency** | Delay in data transmission |
| **Throughput** | Amount of data processed per unit time |
| **Uptime** | Percentage of time system is operational |
| **Error Rate** | Percentage of requests that fail |
| **Conversion Rate** | Percentage of users who complete desired action |

## 🔐 Security Terms

| Term | Definition |
|------|------------|
| **Authentication** | Verifying user identity (login) |
| **Authorization** | Granting permissions to authenticated users |
| **JWT** | JSON Web Token - secure authentication token |
| **Encryption** | Converting data to unreadable format for security |
| **PII** | Personally Identifiable Information |
| **Rate Limiting** | Restricting number of requests from user |

## 📱 Platform-Specific Terms

| Term | Definition |
|------|------------|
| **Service Worker** | Background script for PWA caching and offline support |
| **Offline-First** | Design approach prioritizing offline functionality |
| **Responsive Design** | Layout that adapts to different screen sizes |
| **Touch Target** | Interactive area sized for finger taps (min 48px) |
| **Gesture** | Touch interaction (swipe, pinch, tap) |
| **Hover State** | Visual feedback when cursor is over element |

## 🎯 Business Metrics

| Term | Definition |
|------|------------|
| **Average Check** | Average amount spent per order |
| **Customer Lifetime Value (CLV)** | Total revenue from customer over relationship |
| **Table Utilization** | Percentage of tables occupied during service |
| **Order Accuracy** | Percentage of orders without errors |
| **Customer Satisfaction (CSAT)** | Measure of customer happiness (usually 1-5 scale) |
| **Net Promoter Score (NPS)** | Likelihood customers recommend restaurant |

*This glossary ensures consistent terminology across the development team and stakeholders.*
